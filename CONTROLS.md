# Spectator View — Controls Quick Reference

Active while a table is running and the spectator view is available.

## Modes
| Key | Action |
|-----|--------|
| **F7** | Toggle spectator view (VR: spectator ⇄ mirrored eye) |
| **F5** | Split (VR): mirrored eye **left** + spectator camera **right** |
| **F8** | Cycle preset: Angled → Overhead → Low |
| **F6** | Cycle update rate: every frame → 2nd → 3rd |

## Aim the camera
| Key | Action |
|-----|--------|
| **↑ ↓ ← →** | Pan (up / down / left / right) |
| **`[` `]`** | Tilt angle (shallower / steeper) |
| **KP `+` `−`** | Zoom (field of view) |
| **`,` `.`** | Distance (closer / farther) |

## Save
| Key | Action |
|-----|--------|
| **F9** | Save camera for **this table** (auto-loads next time) |
| **F4** | Reset camera to the current preset |

> Tip: pick a preset (F8), nudge it to frame the table, then **F9** to remember it per table.
> Adjust keys are unbound by default in VPX; if you rebind them, look for the **"Spectator …"** actions.
